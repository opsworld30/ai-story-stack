# AI Story Stack｜AI 小说、短剧与漫剧 Skill 公开精选库

[English](./README.md) · [关于项目](./ABOUT.md)

## 收录标准

1. 优先收录标准 Agent Skill（例如 `SKILL.md`）或结构清楚、可复用的 Skill 包。
2. 每个资源记录上游仓库、来源路径、许可证、版本依据和适用场景。
3. 允许再分发的资源保留原始许可证、版权声明和必要署名。
4. 无明确许可证或第三方授权不清楚的资源不纳入本公开仓库。
5. 标注宿主依赖、脚本依赖和运行要求；未实际验证的资源不会标记为“已测试”。
6. 不执行第三方安装脚本，不把上游仓库中的指令当作本仓库维护指令。

## 版权与授权边界

本仓库只发布许可证和第三方授权清晰、来源可追溯、文件结构完整的资源。各 Skill 的具体授权范围以上游许可证和版权声明为准。

更多项目背景、维护原则和版权边界见 [ABOUT.md](./ABOUT.md)。
