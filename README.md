# AI Story Stack

[简体中文](./README.zh-CN.md) · [About](./ABOUT.md)

A curated public collection of **78 complete functional AI Agent Skill entrypoints** for novel writing, short-drama development, storyboarding, character and scene assets, video prompts, audio, editing, and end-to-end AI production.

This repository contains only Skill packages whose upstream licenses clearly permit redistribution. Each package preserves the required functional file structure, includes its original license, and has an `UPSTREAM.md` source record. Entries without a clear redistribution license are excluded.

**Novel writing:** The category contains 10 complete Skill collections and 35 Skill entrypoints: [Chinese Novelist](./01-novel-writing/PenglongHuang__chinese-novelist-skill/chinese-novelist/README.md), [Oh Story](./01-novel-writing/zenstory-ai__oh-story-claudecode/README.md), [Novel Writing](./01-novel-writing/wgwtest__novel-writing/README.md), [Qiaomu Novel Generator](./01-novel-writing/joeseesun__qiaomu-novel-generator/README.md), [RoleTrace](./01-novel-writing/LCnKeo__roletrace/README.md), [Longform Fiction](./01-novel-writing/oldwinter__skills/README.md), and [Fiction Humanizer ZH](./01-novel-writing/deedeekong07-alt__fiction-humanizer-zh/README.md), [Snowflake Fiction](./01-novel-writing/hestudy__snowflake-fiction/snowflake-fiction/README.md), [Chinese Novel Workflow](./01-novel-writing/wp1020__Chinese-Novel-Workflow/chinese-novel-workflow/README.md), and [Novel Writer](./01-novel-writing/Yunshiro__yunn-skills/novel-writer/README.md).
