# AI Story Stack

A curated collection of AI Agent Skills for novel writing, screenplay adaptation, storyboarding, character and scene assets, video prompting, audio, editing, and end-to-end AI drama production.

## Categories

| Directory | Focus |
|---|---|
| `01-novel-writing` | Novel creation, continuation, revision, and prose craft |
| `02-script-adaptation` | Novel-to-screenplay adaptation, short-drama development, and dialogue |
| `03-storyboard` | Shot design, visual storytelling, camera language, and directing |
| `04-character-asset` | Character sheets, identity consistency, and character references |
| `05-video-prompt` | Video-generation prompts, motion, lighting, and visual style |
| `06-audio-voice` | Voice, dialogue performance, audio and sound design |
| `07-editing-qc` | Editing, script review, continuity, and quality control |
| `08-end-to-end` | End-to-end production workflows and orchestration |
| `09-scene-asset` | Scene, environment, and prop assets |
| `10-agent-tools` | Agent utilities, decision engines, and production helpers |
| `11-knowledge-base` | Reusable production knowledge and reference material |

## Attribution and licensing
