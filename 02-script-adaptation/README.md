# 剧本创作与改编

本分类收录影视、短剧和漫剧的剧本开发能力：小说素材拆解、改编决策、分集大纲、剧本正文、对白与制作前的剧本工程。

**边界说明：** 本分类交付的是可继续制作的分集大纲、场次、动作节拍和台词，不是小说章节正文；镜头拆分与镜头调度归入 [03 分镜与导演](../03-storyboard/README.md)。
