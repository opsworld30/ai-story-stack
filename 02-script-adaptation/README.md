# 剧本创作与改编

本分类只收录**影视与短剧剧本**相关能力：小说影视化拆解、短剧开发、分集大纲、场次设计、动作节拍、对白台词、剧本结构与改编。

**分类边界：** 这里的大纲是分集/分场的剧本开发大纲，不是网络小说的总纲或章节大纲；这里的正文是可拍摄的剧本，不是小说叙述正文。小说写作归入 [01 小说创作](../01-novel-writing/README.md)，镜头拆分和拍摄调度归入 [03 分镜与导演](../03-storyboard/README.md)。
