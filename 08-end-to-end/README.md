本分类收录跨多个制作阶段的总控与流程编排能力，包括决策、制作调度、投喂交付和全流程工作室。

**边界说明：** 单项剧本、分镜、角色资产、视频提示词和质检能力仍放在对应分类；只有跨阶段编排或完整制作管线放在这里。
