# 角色资产

本分类收录角色视觉资产与人物一致性相关 Skill：角色参考图、人物设定、角色形象与声音资产提示词。

**边界说明：** 本分类主要处理角色资产及其描述，不代替小说人物弧光创作；小说人物行为与性格塑造仍归入 [01 小说创作](../01-novel-writing/README.md)。
