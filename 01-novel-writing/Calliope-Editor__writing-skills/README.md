# Calliope Writing Skills｜小说创作训练

Source: https://github.com/Calliope-Editor/writing-skills  
License: MIT

This package contains six fiction-writing craft Skills: character-card development, reverse character analysis, dialogue practice, prose rhythm, psychic distance, and scene architecture.

**Scope:** These Skills coach, interview, and critique. They do not draft or rewrite the author's prose. The writer supplies the manuscript or exercise; the Skills provide structure, questions, and feedback.

| Skill | Purpose |
|---|---|
| [character-card-builder](./skills/character/character-card-builder/SKILL.md) | Build a character card through guided interview |
| [reverse-character-cards](./skills/character/reverse-character-cards/SKILL.md) | Infer character goals, wounds, arcs, voice and relationships from a draft |
| [dialogue-gym](./skills/craft/dialogue-gym/SKILL.md) | Practice conflict, subtext and distinct character voices |
| [prose-rhythm](./skills/craft/prose-rhythm/SKILL.md) | Practice sentence variety, cadence and prose rhythm |
| [psychic-distance](./skills/craft/psychic-distance/SKILL.md) | Practice narrative distance and point-of-view control |
| [scene-architecture](./skills/craft/scene-architecture/SKILL.md) | Practice scene goals, conflict, disaster and sequel structure |

The package is text-only and has no required scripts or external services.
