# Novel Writing｜小说写作 Skill

**定位：** 面向小说文本创作与维护的独立 Skill，不负责剧本格式、分集脚本或影视改编。

## 能力范围

- 小说项目初始化与全书、卷、章、场景规划
- 小说正文起草、续写和局部重写
- 人物视角、知识边界、动机与行动因果检查
- 自然对白与行为链设计，避免把对话写成轮流发言的会议记录
- 角色首次出场、场景结构、现实约束和章节衔接检查
- 修订时保留作者原有文风、节奏、沉默与有意重复
- 作者手改稿、正式稿和过程稿的版本交接
- 可选的稿件文本污染检查脚本
