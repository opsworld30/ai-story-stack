# RoleTrace｜角色决策与人格一致性

**让人物根据自己的认知、欲望、恐惧和现实条件作出选择，而不是替剧情说台词。**

- 上游版本：`fee1361ea45b4bb18ec5d9ad55b628b83eb53b1c`（2026-10-10T03:26:41Z UTC）
- 1 个 Skill 入口，附带对白测试样例

## 核心能力
- AUDIT：审查人物动机、认知、情绪和行为一致性
- REWRITE：在保留剧情事实和作者文风的前提下修对白
- DECIDE：模拟角色在约束下的可能决策
- VOICEPRINT：建立人物表达与判断声纹，检查角色同质化

## 适用边界
适用于小说人物和对白专项分析；不负责整本小说的持久记忆。当前上游版本为实验版 v0.1.0，未执行测试。
