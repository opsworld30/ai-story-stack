# Chinese Novel Workflow

用于中文叙事创作的 Codex Skill。它把网文和长篇叙事的项目管理、设定维护、分卷规划、章节细纲、正文创作、连续性审稿、自然化润色、终审与记忆沉淀组织为一套可执行的工作流。

适用对象包括连载网文、长篇小说、短篇故事、章节续写和已有正文的审读修订。

当前版本：`0.6.26-chapter-detailed-plot-gate`

## 能力范围

- 建立作品定位、世界观、力量体系、势力关系和人物弧光。
- 维护多卷作品的规范目录与卷级规划文件。
- 生成独立章节大纲和场景级章节细纲。
- 为每章生成包含前文衔接包的 AI 创作指令。
- 按既定人称、POV、人物状态、时间线和伏笔创作或续写正文。
- 审核正文的连续性、字数、元信息泄漏、人物跑偏、章节重演和伏笔状态。
- 进行自然化顺读润色、局部去 AI 痕迹扫描和高强度终稿修订。
- 从章节提取记忆，并在位置校验后更新全局设定库。

## 核心原则

1. 先保住故事事实，再改善表达。人物关系、时间线、设定规则、已知信息、伏笔、章节功能和结尾钩子不会在润色中被擅自改写。
2. 章节必须是独立叙事单元。每章承接上一章压力，但不得重复上一章已经完成的事件链或高潮。
3. 先有完整剧情链，后写章节细纲和正文。每章都要具备 `本章详细剧情说明`，交代开场压力、触发、行动、阻碍、升级、选择、结果与结尾状态。
4. 正文只写故事。字数、创作规格、章节备注、审稿记录和流程说明只能保留在设定、纲要、创作指令或审稿文件中。
5. 人称与 POV 必须锁定。第三人称限知不会因为贴近人物心理而变成第一人称叙述。

## 安装

将整个目录放入 Codex skills 目录，保留以下结构：

```text
chinese-novel-workflow/
├── SKILL.md
├── 使用流程文档.md
├── agents/
│   └── openai.yaml
└── references/
    ├── 01-project-setup.md
    ├── 04-outline-workflow.md
    ├── 06-continuity-review.md
    ├── 11-chapter-detail-expansion.md
    └── ...
```

安装后，在 Codex 中显式调用：

```text
使用 chinese-novel-workflow，依据现有设定审核第一卷的卷纲、章节大纲和章节细纲，输出问题报告与修改方案。
```

该 Skill 也支持隐式触发：当任务涉及中文小说的设定、分卷大纲、章节细纲、正文、审稿、润色或记忆管理时，会按任务阶段加载对应规则。

## 推荐工作流

```text
项目规格
-> 项目文件结构
-> 作品定位 / 世界观 / 人物
-> 总纲
-> 分卷卷纲
-> 独立章节大纲（含本章详细剧情说明）
-> 章节细纲
-> 单章 AI 创作指令
-> 单章正文
-> 连续性审核
-> 自然化 / 去 AI 润色
-> 终审
-> 章节记忆
-> 全局设定库更新
```

Skill 会根据当前任务只读取必要的参考文档。例如，分卷与章节规划使用 `references/04-outline-workflow.md`，连续性审稿使用 `references/06-continuity-review.md`，章节细纲展开使用 `references/11-chapter-detail-expansion.md`。

## 项目目录约定

多卷作品采用以下结构：

```text
作品根目录/
├── 设定/
│   ├── 00-作品定位卡.md
│   ├── 01-人物系统.md
│   ├── 02-叙事架构.md
│   ├── 03-写作风格与禁用项.md
│   └── 04-创作规格.md
├── 大纲/
│   ├── 00-总纲.md
│   └── 第01卷/
│       ├── 00-卷纲.md
│       ├── 01-人物设定.md
│       ├── 02-章节大纲.md
│       └── 03-章节细纲.md
├── 创作指令/
├── 正文/
├── 记忆/
└── 终审/
```

`03-章节细纲.md` 是一个卷唯一的章节细纲文件。每章细纲作为该文件内的独立标题区段保存，不建立按章拆分的细纲文件夹，也不在其他目录重复存放卷级人物设定。

## 关键质量闸门

### 章节规划

每个独立章节大纲和细纲必须明确记录：

- `字数规则来源`
- `本章最低字数`
- `本章详细剧情说明`

其中“本章详细剧情说明”必须是按时间顺序排列的完整事件链，不能只用一句简介、关键词或场景标题替代。

### 正文创作

生成单章正文前，Skill 会要求或生成单章 AI 创作指令，并锁定：

- 叙事人称、POV 人物、主角称呼和允许使用的代词。
- 前文衔接包，包括上章结尾动作、未解压力、人物身心状态、已知信息和待回收伏笔。
- 本章最低字数及其来自项目创作规格或章节覆盖规则的依据。
- 本章必须新增与禁止重演的事件。

正文文件中禁止出现 `本章字数`、`字数统计`、`番茄计字法`、`章节备注`、`创作说明`、`以下是正文` 等工作流元信息，也禁止将卷号、章号、后续剧情或作者规划语言直接泄漏进叙述和普通对话。

### 连续性审核

审核会按问题严重程度给出证据、影响与修改方向，重点检查：

- 人物、关系、时间线、设定规则和信息知情范围是否冲突。
- 上下章是否重复同一事件链，或是否缺少新增变化。
- 伏笔是否误回收、遗漏或提前揭示。
- POV、人称和角色声线是否漂移。
- 实际正文字数是否达到已确认的本章最低字数。
- 正文是否混入大纲、字数或作者工作流元信息。

字数未达标时，修改建议必须落到具体场景的动作、阻碍、关系反应、信息释放或转场，不能用重复解释或空泛心理描写硬凑字数。

## 常用调用示例

### 创建或整理项目

```text
使用 chinese-novel-workflow，按多卷连载小说规范整理当前项目目录，并保留已有文件内容。
```

### 编写章节大纲与细纲

```text
使用 chinese-novel-workflow，读取设定、总纲和第一卷卷纲，为第012章补全独立章节大纲与章节细纲。每一项必须包含字数规则来源、本章最低字数和完整的本章详细剧情说明。
```

### 生成正文

```text
使用 chinese-novel-workflow，依据第012章的创作指令写正文，只输出正文；不得输出字数、章节备注或任何生成说明。
```

### 审核并修复规划文件

```text
使用 chinese-novel-workflow，重新审核第一卷设定、卷纲、章节大纲和章节细纲的连续性与格式问题，在本地生成完整问题报告、详细修改方案，并对已完成的修复标记“已修复”。
```

### 轻度顺读润色

```text
使用 chinese-novel-workflow，对指定章节做自然化顺读润色。锁定剧情事实、POV、人物关系、伏笔和结尾钩子，只修改表达，不改写情节。
```
