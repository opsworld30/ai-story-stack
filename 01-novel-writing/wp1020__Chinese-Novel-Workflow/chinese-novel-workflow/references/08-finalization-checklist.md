# Finalization Checklist

Use this before saving, publishing, ingesting into memory, or treating a narrative unit as canon.

## Decision Labels

- Can finalize: only minor polish remains.
- Needs revision: fix listed issues before saving.
- Do not finalize: blocking continuity or story problems remain.

## Checklist

```markdown
## 定稿检查
- 剧情事实一致:
- 润色未改变剧情事实:
- 人物声线稳定:
- 润色未改变人物动机 / 人物阶段:
- 润色未改变人物关系姿态:
- 润色未改变角色认知边界:
- 角色认知无越界:
- 时间线可成立:
- 设定/能力/现实逻辑无冲突（跨时代技术细节泄漏、物理现象与时代不匹配等）:
- 伏笔未误删:
- 结尾钩子 / 情绪落点有效:
- 正文字数满足本章最低字数:
- 章节位置 / 卷状态判断有来源依据:
- AI 味残留可接受:
- 是否适合入库:
```

## Save-Gate Rules

Do not recommend finalization if:

- A character acts on information they should not know.
- A canon rule is contradicted.
- A major relationship changes without scene support.
- The ending pull, payoff, hook, or aftertaste is missing or accidentally resolved.
- A new fact would poison future memory if saved.
- Actual prose word count is below the chapter minimum and no author-approved exception exists.
- Chapter-position, volume-ending, arc-ending, or book-ending claims rely only on prose tone, ending atmosphere, or payoff feeling.
- The unit is mostly exposition with no state change, emotional turn, or narrative purpose.

## Rules

- Be stricter before memory ingestion than during drafting.
- Distinguish prose polish from canon risk.
- If context is missing, state what must be checked against previous narrative units.
- Do not approve a unit only because the prose is smooth.
- Do not approve unsupported "本卷结束", "阶段收束", "主线告一段落", "全书进入尾声", or "最终结局临近" as ingestible memory.
