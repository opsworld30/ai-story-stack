# 小说创作

本分类只收录**小说文本本身的创作与维护**：网文、长篇、短篇、题材与故事设定、小说大纲、人物塑造、章节正文、续写、修订、拆文分析和连载管理。

**分类边界：** 小说大纲是为小说章节与正文服务的结构；小说正文以叙述、描写、人物行动和对话构成。影视/短剧的分集大纲、场次表、动作节拍、台词本和剧本不放在本分类。

**当前公开完整功能 Skill 包：1 个。**
