# Calliope Writing Skills｜小说稿件编辑与读者反馈

Source: https://github.com/Calliope-Editor/writing-skills  
License: MIT

This package contains seven fiction editorial and critique Skills. They read and assess existing manuscripts, simulate reader/editor responses, and report issues without silently rewriting the author's prose.

| Skill | Purpose |
|---|---|
| [agent-first-pages](./skills/critique/agent-first-pages/SKILL.md) | Simulate a literary agent's cold read of opening pages |
| [beta-reader-panel](./skills/critique/beta-reader-panel/SKILL.md) | Gather chapter-by-chapter reactions from distinct reader personas |
| [workshop-critique](./skills/critique/workshop-critique/SKILL.md) | Run a structured multi-voice fiction workshop critique |
| [continuity-editor](./skills/editorial/continuity-editor/SKILL.md) | Check character facts, timeline, world rules and knowledge state |
| [copy-editor](./skills/editorial/copy-editor/SKILL.md) | Check spelling, punctuation, grammar and house style |
| [developmental-editor](./skills/editorial/developmental-editor/SKILL.md) | Diagnose structure, pacing, character arcs and causality |
| [line-editor](./skills/editorial/line-editor/SKILL.md) | Diagnose sentence-level rhythm, clarity, voice and overwriting |

These are editorial/critique Skills, not screenplay tools. No scripts or external services are required.
